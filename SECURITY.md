# Security policy

Soul Society is research-alpha software and has not received an independent
security audit. Do not use it to protect funds, production secrets, or critical
decisions.

## Reporting

Please use a private
[GitHub security advisory](https://github.com/AbdelStark/soulsociety/security/advisories/new).
Do not include exploit details in a public issue.

Include the affected commit, impact, threat scenario, minimal reproduction, and
suggested mitigation if available. Avoid accessing other people's data or
infrastructure while investigating.

The project will acknowledge a report when maintainers are available, validate
it, coordinate a fix and disclosure, and credit the reporter if requested. No
response-time SLA or bounty is currently offered.

## Supported versions

Only the latest commit on `main` is supported during research alpha. There are
no security-supported releases yet.

The system's precise claim and assumptions are documented in
[docs/security-model.md](docs/security-model.md).
